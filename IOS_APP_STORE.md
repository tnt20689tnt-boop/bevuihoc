# BÉ VUI HỌC — iOS / App Store

## Current iOS integration

- Native container: Capacitor 8.
- Bundle identifier: `vn.bevuihoc.app` (confirm availability and ownership in Apple Developer before release).
- Display name: `Bé Vui Học`.
- Supported device families: iPhone and iPad (universal iOS target).
- Existing game and Supabase backend remain on the current production app.
- The current TanStack Start app is server-rendered. The Capacitor shell therefore points to the existing HTTPS production origin rather than pretending that the server output is a static web bundle.
- Native integrations currently prepared: iOS status bar handling and light haptic feedback for tappable controls.

## Requirements

- macOS with Xcode 26 or later.
- Node.js 22+ and Bun.
- An Apple Developer Program membership.
- An App Store Connect app record, a registered Bundle ID, signing certificate and provisioning profile.
- Final app icon, screenshots for supported iPhone/iPad sizes, support URL and privacy-policy URL.

## Generate the native iOS project

Run from the repository root on macOS:

```bash
bun install
bun run ios:add
bun run ios:sync
bun run ios:open
```

In Xcode:
1. Select the `App` target and confirm the Bundle Identifier.
2. Select the Apple Developer Team under Signing & Capabilities.
3. Confirm the iOS deployment target and iPhone/iPad device family.
4. Test on physical iPhone and iPad, including login, 3D rendering, touch controls, audio, document/library views, and network-loss recovery.
5. Create an Archive and validate it in App Store Connect before submission.

## Important App Review release gate

This first integration uses a remote HTTPS origin because the existing project is a server-rendered application. It is a native Capacitor shell, not an offline-bundled copy of the game. Do not submit it as final until the iOS experience has been tested and has sufficient native value beyond simply displaying the website. Apple Guideline 4.2 warns against apps that are essentially websites or web clippings. The interactive 3D learning world, touch-first controls, and native integrations must work reliably and be clearly demonstrated to App Review.

Before submission, complete the privacy disclosures, age rating and Kids Category decision, account-deletion path if users can create accounts, parental/privacy safeguards, and working support/privacy links. Supply a review account if sign-in is required. Do not include real children's personal data in screenshots or review notes.
